# Icon assets

The pixel icons and scrollbar bitmaps in this folder come from the Typecho
"win95" theme (`assets/img`), which served as the visual reference for this
Docsify theme.

Files copied from that theme:

- `computer.png`
- `disk.png`
- `folder.ico`
- `file.ico`
- `file.png`
- `up.png`, `down.png`, `left.png`, `right.png`
- `track.png`, `pixel-alt.png`
- `favicon.ico`

The SVG icons (`exe.svg`, `recycle.svg`, `help.svg`, `shutdown.svg`, `run.svg`,
`views.svg`, `notepad.svg`, `browser.svg`) were drawn for this project.

If you redistribute the theme, check the original Typecho theme's license and
replace these bitmaps with your own if necessary. They are ordinary 16×16
Windows 95-style pixel icons, not Microsoft system files.
