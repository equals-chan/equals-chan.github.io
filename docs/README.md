# 欢迎来到 Win95 Docsify 👋

这是一个把 **Docsify** 变成 **Windows 95 桌面**的主题。

左侧的目录不再是一条普通的侧边栏，而是一台老电脑里的资源管理器：

- `开始使用`、`使用指南` 这些分组会变成 **文件夹**
- 每一篇 Markdown 文档会变成 **文件**
- 点击文件，会打开一个可以拖动、缩放、最小化、最大化的 **WinBox 窗口**
- 侧边栏里的外部链接或 `.exe` 链接，会变成 **程序窗口**，内容通过 iframe 嵌入

> 这是一个主题，不是一个真正的操作系统。它不会格式化你的 C 盘。

## 现在可以试试

1. 拖动这个窗口的标题栏。
2. 从窗口右下角拖动来改变大小。
3. 点击右上角的 `_` 最小化到任务栏，再点任务栏按钮恢复。
4. 打开开始菜单，运行 `Notepad.exe`。
5. 在资源管理器里双击文件夹，或者点击地址栏旁边的 `Up`。

## 这个主题能做什么？

| 功能 | 说明 |
| --- | --- |
| 文件夹树 | `_sidebar.md` 的嵌套列表自动变成文件夹，分隔条可左右拖动 |
| 文档窗口 | 每篇文档打开一个独立窗口，可以同时开很多个 |
| 任务栏 | 每个窗口都有任务栏按钮，点击可以切换或最小化 |
| 开始菜单 | 包含资源管理器、程序、运行、关机等入口 |
| 程序窗口 | 外部链接、`.html`、`.exe` 链接通过 iframe 打开，可自定义图标 |
| 桌面图标 | 可配置动作和自定义图标 |
| 启动画面 | 刷新页面会看到 "Starting Windows 95" |
| 关机彩蛋 | 开始菜单 → Shut Down...，然后点一下黑屏重新启动 |

## 一个最小的配置

```js
window.$docsify = {
  name: 'Win95 Docs',
  loadSidebar: true,
  homepage: 'README.md',
  plugins: [/* ... */],
  win95: {
    boot: true,
    drive: 'C:',
    rootName: 'My Computer',
  },
};
```

主题脚本会把自己注册成 Docsify 插件，所以只要在 Docsify 初始化之前加载它即可。
