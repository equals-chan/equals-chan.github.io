# 窗口、任务栏与开始菜单

## 窗口

每个文档和程序都是一个 WinBox 窗口。

| 操作 | 效果 |
| --- | --- |
| 拖动标题栏 | 移动窗口 |
| 拖动边缘或角落 | 调整大小 |
| 双击标题栏 | 最大化 / 还原 |
| `_` 按钮 | 最小化到任务栏 |
| `□` 按钮 | 最大化 / 还原 |
| `×` 按钮 | 关闭 |
| 点击窗口内部 | 把窗口置于最前 |

活动窗口的标题栏是蓝色渐变，非活动窗口是灰色。

## 任务栏

底部任务栏是窗口的生命线：

- 每个打开的窗口都有一个按钮
- **活动窗口**的按钮呈按下状态
- 点击活动窗口按钮 → 最小化
- 点击非活动窗口按钮 → 恢复并置于最前
- 点击最小化窗口按钮 → 恢复
- 右侧托盘显示时钟，鼠标悬停可以看到日期

## 开始菜单

点击左下角的 **Start** 按钮。

默认包含：

- `My Computer`：打开资源管理器
- `Documentation`：打开第一篇文章
- 所有程序（侧边栏里的外部链接 / `.html` / `.exe` 链接）
- `Run...`：输入文档路径或网址
- `Shut Down...`：关机彩蛋
- `About Win95 Docsify`：关于窗口

### Run

可以输入：

```text
#/guide/install
https://example.com
docs/apps/notepad.html
```

- `#/...` 或 `.md` → 文档窗口
- `http(s)://` → iframe 程序窗口
- 其他路径 → 也按程序处理

### Shut Down

选择 `Yes` 之后会关闭所有窗口，然后出现经典黑屏：

```text
It's now safe to turn off your computer.
```

点击黑屏即可重新启动（刷新页面）。

## 桌面图标

默认桌面图标：

- `My Computer`
- 第一篇文章
- 第一个程序
- `Recycle Bin`

`Recycle Bin` 会打开一个“回收站是空的”对话框。是的，它不会真的删除任何东西。

可以用 `win95.desktop` 自定义，详见 [主题选项](/guide/options)。

## 启动画面

刷新页面时，会先看到：

```text
Windows 95
DOCSIFY EDITION
Starting Win95 Docsify...
```

大约半秒后进入桌面。可以设置 `boot: false` 关闭。

## 键盘

| 按键 | 效果 |
| --- | --- |
| `Escape` | 关闭开始菜单和下拉菜单 |
| `Enter` / `Space` | 在资源管理器中打开当前聚焦的文件 |
| `Alt+Left` / `Alt+Right` | 浏览器会尝试前进后退（会改变 hash，但不会自动打开窗口） |

> 窗口本身由 WinBox 管理，键盘焦点会跟随浏览器默认行为。
