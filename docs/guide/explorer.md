# 文件夹与文件

## 目录是怎么变成文件系统的？

主题在 Docsify 渲染完 `_sidebar.md` 之后，读取侧边栏的 DOM：

- 嵌套列表里的**分组标题** → 文件夹
- 分组里的**链接** → 文件
- 根节点 → `My Computer` → `C:`

```md
- 开始使用

  - [欢迎](README.md)
  - [安装](guide/install.md)

- 程序

  - [记事本](apps/notepad.html ':class=w95-exe')
```

```text
My Computer
└── C:\
    ├── 开始使用\
    │   ├── 欢迎.md
    │   └── 安装.md
    └── 程序\
        └── 记事本.exe
```

## 文件名规则

| 侧边栏内容 | 显示为 | 打开方式 |
| --- | --- | --- |
| `[欢迎](README.md)` | `欢迎.md` | 文档窗口 |
| `[快速开始](quickstart.md)` | `快速开始.md` | 文档窗口 |
| `[记事本](apps/notepad.html ':class=w95-exe')` | `记事本.exe` | iframe 程序窗口 |
| `[Example](https://example.com)` | `Example.exe` | iframe 程序窗口 |

文档默认补 `.md`。如果标题本身已经带 `.md`，则不再重复添加。

## 资源管理器操作

- **单击文件**：打开文档窗口
- **单击文件夹**：进入文件夹
- **单击左侧树里的 `+` / `−`**：展开或折叠
- **拖动中间分隔条**：调整文件夹树和文件列表的宽度
- **双击分隔条**：重置为 200px
- **分隔条聚焦后按 `←` / `→`**：键盘微调宽度
- **Back / Forward**：在文件夹历史里前进后退
- **Up**：回到上一级
- **Views**：在“大图标”和“详细信息”之间切换
- **View 菜单**：也可以切换视图、刷新
- **Address**：显示当前路径，例如 `C:\使用指南`

> 层级很深、文件名很长时，把分隔条往右拖即可看到完整的树。宽度会在重新打开资源管理器后保留。

## 视图模式

### 大图标

Win95 默认的文件夹视图。图标使用 16×16 像素图标放大到 32×32，保持像素感。

### 详细信息

显示名称、类型、大小、修改时间。修改时间是主题虚构的 `1995/8/24`，只是为了气氛。

## 状态栏

左侧显示：

- 当前文件夹的对象数量，例如 `4 object(s)`
- 选中文件后的名称和类型

右侧显示当前路径。

## 多个窗口

每篇文档都会打开一个独立窗口。你可以：

1. 同时打开多篇文档并排查看
2. 把窗口拖到任意位置
3. 最小化到任务栏
4. 最大化到整个桌面（任务栏仍然保留）

再次点击同一个文件时，如果窗口已经存在，会把它恢复并置于最前，而不是重复打开。

## 排序

文件夹永远排在文件前面，然后按名称自然排序（`2` 在 `10` 前面）。

> 文件系统结构来自侧边栏，但每一层都会按名称重新排序（文件夹优先）。
